## 型1　クロス円の東京時間の安値割れ → 戻り売り（3分の1と3分の2に分けて入る）

**オーナーの言葉**（2026-11-16 14:42〜14:44 の MT5 の5分足の画面3枚＝ドル円・ポンド円・ユーロ円と一緒に）：

> クロス円で下げて、日本時間の最安値を更新。最安値から半分戻したところで3分の1エントリー。水平線のところまで来たら残り3分の2をエントリー。そこから上に抜けて伸びそうだったら損切りしたいと思っていました。

**型（11/16 オーナーの答えで決まったところまで）**

1. 東京時間に、クロス円（ドル円・ポンド円・ユーロ円…）が**そろって**下げる
2. その日の東京時間の安値（画面の赤い水平線）を割って、新しい安値をつける
3. **半値＝新しい安値と水平線のちょうど真ん中**（11/16 オーナー「最安値から水平線までの半分を半値として、そこで3分の1入れます」）。そこまで戻ったら売りを **3分の1**
4. **水平線**（割った安値＝今度は上の壁）まで戻ったら、残りの **3分の2** を売って満玉。**線まで来なければ 3分の1 のまま**（オーナー「水平線まで行けばフルで入りますが、行かなければそのまま」）
5. 水平線を**上に抜けて伸びそう**なら損切り
6. **利確＝下にある、弱い方のユーロ（ユーロ円）のピボットに届いたとき**（オーナー「下に弱い方のユーロのピボットに到達したとき利確します」）

**まだ決まっていないこと**（決まったらここに書く）

- 利確のピボットは**どれか**：日足（その日の S1＝前の営業日の高値・安値・終値から）か、週足（WS1＝前の週から）か。オーナーのポンド円の画面の「WPP 211.46」は、ふつうの式（高値＋安値＋終値）÷3 で先週の値から出した 211.435 とほぼ同じ＝この式で計算できる
- 「弱い方のユーロ」の意味：下げのいちばん強いペア（この日はユーロ円）のピボットを見る、で合っているか。**どのペアで入るか**（ユーロ円だけか、クロス円の全部か）。ほかのペアで入っても、利確の合図はユーロ円のピボットか
- 損切りの数字（水平線の何 pips 上か・5分足の終値で見るか）／見る時間足（画面は5分足）／何時までに戻らなければやめるか
- 半値の「新しい安値」は、そのときまでのいちばん安い値（戻る前にさらに下げたら、半値も下にずれる）として扱うか

# 高値更新の事例帳（手で書く・続伸とだまし）

2026-10-09 オーナー「年初の高値を更新してさらに上げたものと、だましで下げたもの、特徴を蓄積して保存しておいてください」で新設。

- **数字の台帳は自動**＝`highs-ledger.csv`／`highs-ledger.md`（J44・`highs_ledger.py`・jp-highs.yml が毎日書く）。年初来高値と**上場来高値**（md は「A. 年初来（全部）」と「B. 上場来だけ」の2部・CSV は kind 列で絞れる）を更新した全銘柄の、その日の特徴と次の日・5日後の値動き（続伸・横ばい・だまし）がたまる
- **この帳面は手で書く**＝台帳に入らないこと（材料・大株主の売り買い・板の様子・テーマの流れ）を、セッションで読み解いたときに1件ずつ足す。いちばん新しい日を上に
- 区切り（J44 と同じ）：次の日の終値どうしで +1％以上＝続伸・−1％以下＝だまし
- ⚠️ ここの「目安」は**候補で、まだ確かめていない**。決まりにするなら事前登録して、登録より後のケースだけで確かめる

## だましを疑う目安（候補・2026-10-09 の2件から）

上場来・年初来の高値を更新しても、次のうち3つ以上が重なれば だましを疑う：

1. 上場から1年以内（「上場来」の歴史が短い）
2. 数日で +40％以上・S高を何度も付けた急な上げ
3. 25日線から +30％以上、上にある
4. 前の日の売買代金がふだんの10倍前後（目印C の強いほう）
5. 更新幅がわずか（数％以内）で、前に押し返された値段の近く
6. 大株主の持ち株の減少の報告・売出し・分売など、上で売りが出る話がある

反対に、上場から長い株がじわじわ上げて更新したもの（25日線から +20％未満・売買代金の倍率が小さい）は素直に続きやすかった（同じ日の10件）。

## 研究で確かめ済みのこと（数え直さない）

- 高値更新の翌朝に寄りで買う＝平均で負けやすい（費用後 −0.11〜−0.22％）。窓 +1％以上で寄るとさらに弱い（−0.15〜−0.34％・小さい株ほど強い）（J10・J11）
- 前の日の売買代金が20営業日平均の5倍以上＝寄りのあと下げやすい（ふつうの株より寄り→大引け −0.35〜−0.46％・18年すべて同じ向き・10倍以上は −1.00％）（J26・目印C）
- 前の日の上ヒゲが長い・前の日に52週高値を更新した、だけでは翌日の弱さは見えない（J10 Q3・J22 F10・F11）

## スクリプト概要

```python
import json, math
from datetime import datetime

with open("signals-log.json") as f:
    data = json.load(f)
signals = data if isinstance(data, list) else data.get("signals", [])
closed = [s for s in signals if s.get("outcome") in ["tp1","tp2","sl"]]

# Wilson 95% CI
def wilson_ci(k, n, z=1.96):
    if n == 0: return (0.0, 1.0)
    p = k/n
    denom = 1 + z**2/n
    center = (p + z**2/(2*n)) / denom
    margin = (z * math.sqrt(p*(1-p)/n + z**2/(4*n**2))) / denom
    return (max(0, center-margin), min(1, center+margin))

def r_result(s):
    o = s.get("outcome")
    if o == "tp1": return 2.0
    if o == "tp2": return 3.0
    if o == "sl": return -1.0
    return 0.0

def get_env(s):
    e = s.get("environment")
    if isinstance(e, dict):
        return e.get("env_score", "?")
    return "?"
```

- env=B（注意）のCI上限が43.8%。全体ベースライン(42.8%)から下寄りの傾向。

- env=D はN=63のみ。CI=[32.8%〜56.7%]で完全に不明。
- 「警戒スコアが高い=入るな」という単純なルールは、このデータからは支持されない。
- ただしenv=Bのみ、全体よりやや低い傾向がある（CI上限43.8%）。

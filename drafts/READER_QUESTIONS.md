# 🔎 読者の質問キュー（「それ、本当？」検証室）

2026-09-23 新設。受付ページ＝`guide-sore-honto.html`（読者がメールで「投資の定説」を送る）。
ここに並んだ質問を、`signal-lab-daily`（毎朝 06:10）が研究日誌の題材として確かめる。決まりの本体は `SIGNAL_LAB_SOP.md` の「読者の質問」。

## 🚨 絶対の決まり

- **このファイルは公開リポジトリにある。個人情報を1文字も書かない**（メールアドレス・名前・ニックネーム・届いた時刻など、本人がわかるものすべて）。書くのは質問の中身だけ。
- 受け付けるのは **手法・ルール・定説の検証だけ**。個別銘柄の判断、将来の値段、その人のお金の配分は受け付けない（無登録の投資助言になる）。
- **routine はこのファイルを編集しない。** 回答済みかどうかは、`signal-lab-ledger.md` に `読者Q-NNN` が出ているかで判断する。

## 振り分けの手順（Claude のセッションで。オーナーが「質問来てる？」と聞いたとき・週1目安）

1. Gmail で件名に「それ、本当？」を含むメールを探す。
2. 受け付ける質問かを判断する（上の決まり）。
3. `signal_lab_verify.py` の `ALLOWED_FILTER_KEYS` で確かめられるかを見る。
   - 確かめられない → 下の「受付できなかった質問」に理由だけ書く。本人への返信は下書きを作り、オーナーが送る。
   - 確かめられる → 「受付中」に1行足して push。
4. 研究日誌が公開されたら（台帳に `読者Q-NNN`）、本人に記事の URL を返信する（下書き→オーナーが送る）。
   - 返信には **記事のお知らせだけ** を書く。メルマガや広告の案内は入れない（特定電子メール法の「広告宣伝メール」にしないため）。

## 返信で守ること（2026-09-23 コンプラ点検＝白。その条件）

- **返信は事務連絡だけ**：「受け付けました」「記事にできるか（できない理由）」「記事の題名と URL」まで。質問者の持ち高や売買のよし悪し、「いつ・何を」の判断は、無料でも書かない。
- **お知らせは1人に1回**。お礼と記事の題名・URL だけ。メルマガの案内・ほかの記事の宣伝・広告やアフィリエイトのリンクは入れない。
- **質問者を MailerLite に登録しない**（本人が登録フォームから申し込んだ場合だけ）。
- 届いた質問メールは、依頼の記録として Gmail に残す（消さない）。
- **質問への回答を有料の特典にしない**（note・会員・投げ銭など）。報酬と結びつくと無登録の投資助言になる。
- 記事は一般的な集計のままにする。質問者個人の状況に寄せて書かない。
